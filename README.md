# 健行学堂 · Academy of Inspirations（概念网站）

「企业家决策心智与幸福领导力计划」的单页网站概念稿。设计取向：科研机构式的克制排版，配合《国家地理》式的大幅影像与黄色标记。

- 纯静态：`index.html` + `assets/css/site.css` + `assets/img/`，无需构建
- 本地预览：直接用浏览器打开 `index.html`
- 发布：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`；地址为 `https://edwardchina2023-max.github.io/flow/`
